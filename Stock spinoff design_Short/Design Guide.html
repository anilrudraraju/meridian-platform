Overview

Meridian-SS is a research workstation for spinoff and special-situation investing. The UI centers on a Dimension Workspace — a 5-category analysis framework that guides analysts through stock evaluation using the Greenblatt framework:

📊 Dimensions:
S
Setup
B
Business
C
Capital
V
Valuation
I
Incentives

Each dimension has 7 criteria (35 total) that analysts must research using documents from SEC filings, management calls, etc.

Screen Flows

Navigation Structure

App ├── Portfolio Hub (default) │ ├── Active tab │ ├── Closed tab │ └── Watching tab │ └── Card → Workspace │ ├── Decision Journal │ └── Entry list → Detail view │ ├── + New Analysis │ └── Intake modal → Workspace │ └── Workspace (4-step process) ├── 📊 Dimensions │ ├── 5 DimCards (grid) │ ├── Click → DimDetail (inline) │ └── Adjust weights panel ├── 💬 Ask corpus ├── 🤖 Committee └── 📖 Journal

Key UI Patterns

  • Inline expansion: DimCard → DimDetail (no modal)
  • Tab navigation: 4 tabs in Workspace (dims, corpus, committee, journal)
  • Grid layout: 5 dimension cards in responsive grid
  • Tweaks panel: Modal overlay for weight adjustment
  • Portfolio tabs: Active, Closed, Watching (card list per tab)
  • Journal entry: 2-column layout (list + detail)
