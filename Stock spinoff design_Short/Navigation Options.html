Investment Analysis Navigation

Three organizational approaches for the Meridian-SS top-level structure. Each balances the 4-step analysis process with portfolio/watchlist/journal management differently.

Option 1: Process-Centric

Sequential tabs mirror the workflow exactly

⚙️ Current Analysis
The 4-step process
📊 Portfolio
All completed analyses
Revisit & update
👁️ Watchlist
Tracking only
📖 Decision Journal
Trend insights
✓ Pros
• Mirrors 4-step workflow
• Clear mental model
• Simple navigation
✗ Cons
• "Current Analysis" isolates work-in-progress
• Portfolio feels secondary
• Disconnects analysis from outcome

Option 2: Portfolio-First

Portfolio hub organizes everything

📊 Portfolio
📌 Active (3)
✓ Closed (12)
👁️ Watching (8)
📖 Decision Journal
Trends & patterns
➕ New Analysis
Start 4-step process
✓ Pros
• Portfolio = source of truth
• Natural mental model
• Cleaner structure
✗ Cons
• 4-step process less visible
• New users might not know where to start
• Hides the workflow

Option 3: Hybrid (Recommended)

Portfolio hub + modal analysis view

📊 Portfolio Hub
Active | Closed | Watching
Cards show status
Click → Workspace modal
📖 Decision Journal
Right sidebar or panel
➕ New Analysis
Modal or separate view
✓ Pros
• Portfolio central & always visible
• 4-step process 1 click away
• Keeps workflow low-friction
• Journal accessible while analyzing
✗ Cons
• Requires solid modal/detail UX
• Slightly more complex navigation
